# Раздача ассистента как .exe

Standalone CPU-сборка: один `Gaida.exe`, которому не нужен установленный Python.
Голос работает на CPU (`faster-whisper` + `vosk`), без GPU/CUDA.

## Сборка (на машине разработчика)

```powershell
.\build-exe.ps1            # обычная сборка
.\build-exe.ps1 -Clean     # пересоздать окружение сборки с нуля
```

Скрипт:
1. создаёт **чистое CPU-окружение** `.venv-build` (без GPU-пакетов — иначе в exe
   утянулся бы ~1 ГБ CUDA-библиотек);
2. собирает фронт панели (`apps/web/dist`), если он ещё не собран;
3. генерит иконку и собирает exe по `assistant.spec`;
4. кладёт `config.yaml` (и `.env.example`) рядом с exe.

Результат — `dist\Gaida.exe`.

## Что положить рядом с exe (это и есть «дистрибутив»)

`Gaida.exe` читает изменяемые данные **из своей же папки** (не изнутри себя). Поэтому
рядом с exe должны лежать:

```
dist\
  Gaida.exe
  config.yaml          # настройки (копируется при сборке)
  .env                 # ключи: ANTHROPIC_API_KEY=... / OPENAI_API_KEY=...
  wake_phrases.txt     # опционально (калибровка wake word)
  models\
    faster-whisper-small\   # STT-модель
    vosk-model-small-ru\    # wake word
```

Модели **не зашиваются** в exe (большие) — папку `models\` нужно положить рядом и
раздавать вместе с exe (или дать пользователю скачать через `download_model.py` /
`download_wake_model.py` на машине-разработчике и скопировать).

В `config.yaml` для CPU-раздачи имеет смысл выставить:
```yaml
stt:
  device: cpu
  compute_type: int8
```
(если оставить `cuda`, на машине без видеокарты `src/voice.py` сам откатится на CPU/int8).

## Как пользователь это запускает

- Двойной клик по `Gaida.exe` → иконка в системном трее (справа внизу).
- Двойной ЛКМ по иконке → откроется панель в браузере.
- ПКМ по иконке → запуск/стоп/перезапуск сервера, тумблер автозапуска с Windows, выход.

Поведение старта задаётся секцией `tray` в `config.yaml`
(`start_server`, `open_browser_on_launch`).

## Замечания

- **TTS по умолчанию (`edge`)** требует интернета. Офлайн — переключить `tts.engine: pyttsx3`.
- Первый запуск может ловиться SmartScreen (неподписанный exe) — «Подробнее → Выполнить».
- Логи приложения (включая сервер) пишутся в `logs\app.log` рядом с exe.
