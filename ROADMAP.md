- [x] **Локализация интерфейса EN + RU.** Готово: `react-i18next` + `shared/i18n`

  localStorage, по умолчанию RU.

  палитра с зелёным фосфором и Claude-кораллом, рамки-боксы с уголками, едва заметные
  сканлайны + тумблер **CRT mode** (сканлайны/вигнетка/фликер/свечение), микро-
  интерактивности (мигающий курсор, hover-глитч, вдавливание кнопок, диоды статуса,
  ламповый VU-метр). Переделаны все примитивы `shared/ui`.
- [ ] Кнопка мьюта/паузы прослушивания (быстро «не слушай сейчас») отдельно от Стоп.
- [ ] Счётчик токенов и примерной стоимости на ответ (модели платные).

## Запуск / трей

- [x] **Иконка в системном трее Windows** (`src/tray.py`, pystray + Pillow). Двойной ЛКМ —
  открыть панель в браузере; ПКМ — запуск/стоп/перезапуск сервера, тумблер автозапуска с
  Windows (реестр `HKCU\...\Run`), выход. Цвет иконки = статус сервера. Ярлык `Nixi.lnk`
  генерится `install-tray.ps1` (двойной клик + закрепление на панели задач). Поведение
  старта — секция `tray` в `config.yaml` (`start_server`, `open_browser_on_launch`).
- [x] **Standalone CPU-`.exe`** (PyInstaller) — раздача без установленного Python. `build-exe.ps1`
  + `assistant.spec` собирают `dist/Gaida.exe` (~122 МБ) в чистом CPU-окружении `.venv-build`
  (без CUDA). Голос на CPU (ctranslate2 + vosk). Раздача — DISTRIBUTION.md (рядом с exe:
  config.yaml, .env, models/). Самопроверка: `Gaida.exe --selftest`.
- [ ] Шаг в `build-exe.ps1` для дистрибутива: автоматически копировать `models/` рядом с exe
  и проставлять CPU-режим (`stt.device: cpu`, `compute_type: int8`) в копии `config.yaml`.
- [ ] Вынести `start_server` / `open_browser_on_launch` в настройки веб-панели (сейчас только в config.yaml).
- [ ] Быстрый мьют и индикатор состояния движка прямо в трей-меню (через WS-события).
