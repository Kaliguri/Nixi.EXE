# Home AI Voice Assistant

Домашний голосовой ассистент на базе облачных LLM (**Claude** и **GPT**, переключаются голосом), с распознаванием речи, синтезом речи и локальными скиллами. Референс по поведению — умная колонка «Алиса», но мозг — ChatGPT/Claude.

## Архитектура

```
голос ──▶ запись (VAD) ──▶ STT (faster-whisper, GPU) ──▶ Router
                                                            │
                          ┌── локальный скилл? ──── да ─────┤  («включи музыку», «который час»)
                          │                                 │
                          └── нет ──▶ LLM (Claude / GPT) ────┘
                                                            │
                                            ответ ──▶ TTS ──▶ динамик
```

Двухуровневая обработка как в Home Assistant: простые команды отрабатывают скиллы мгновенно, остальное уходит в LLM.

## Быстрый старт (Windows / PowerShell)

```powershell
# 1. Установка (создаст .venv, поставит зависимости, создаст .env)
.\setup.ps1            # ядро + голосовой стек
# .\setup.ps1 -GPU       # + CUDA-ускорение распознавания (~1ГБ, нужна NVIDIA)
# .\setup.ps1 -CoreOnly  # только ядро (без голоса)

# 2. Скачай модель распознавания речи (для голосового режима, ~484МБ)
.\.venv\Scripts\python.exe download_model.py

# 3. Впиши ключи в .env
#    ANTHROPIC_API_KEY=...   (https://console.anthropic.com/)
#    OPENAI_API_KEY=...      (https://platform.openai.com/api-keys)

# 4. Запуск
.\run.ps1              # текстовый режим (чат в консоли)
.\run.ps1 -voice       # голосовой режим (микрофон + динамик)
```

> Для голосового режима нужны микрофон и колонка/динамик. Активация записи —
> по нажатию **Enter** (push-to-talk). Wake word («Окей, Гайда») добавим следующим шагом.
>
> **GPU vs CPU.** По умолчанию `config.yaml` → `stt.device: cuda`. Если не ставил `-GPU`,
> переключи на `stt.device: cpu` и `compute_type: int8` — распознавание пойдёт на процессоре
> (для модели `small` это пара секунд на фразу).

## Переключение моделей

- Напиши/скажи **«Клод, ...»** — запрос уйдёт в Claude.
- **«ГПТ, ...»** — в GPT.
- Просто **«клод»** / **«гпт»** — переключает модель по умолчанию до следующей смены.

Модели и их триггеры настраиваются в [`config.yaml`](config.yaml).

## Скиллы

Локальные команды живут в [`src/skills.py`](src/skills.py). Сейчас есть:
- **музыка** — «включи музыку» (Spotify / YouTube Music)
- **время/дата** — «который час», «какое сегодня число»

Добавить свой: наследуйся от `Skill`, реализуй `match()` и `run()`, добавь в `Skills.__init__`.

## Конфигурация

Всё в [`config.yaml`](config.yaml): имя ассистента, модель по умолчанию, модели Claude/GPT,
параметры STT (модель Whisper, `cuda`/`cpu`), TTS, длительность записи.

## Статус и план

- [x] Голосовой режим: запись с VAD, faster-whisper (STT), edge-TTS (рус. голос)
- [x] GPU-ускорение распознавания (CUDA 12 + cuDNN через pip, без системного CUDA)

  config.py            загрузка конфига и .env
  llm.py               агенты Claude/GPT + Router
  skills.py            локальные скиллы
