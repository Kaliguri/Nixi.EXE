# Home AI Voice Assistant

Домашний голосовой ассистент на базе облачных LLM (**Claude** и **GPT**, переключаются голосом), с распознаванием речи, синтезом речи и локальными скиллами. Референс по поведению — умная колонка «Алиса», но мозг — ChatGPT/Claude.

## Архитектура

```
голос ──▶ запись (VAD) ──▶ STT (faster-whisper, GPU) ──▶ Router
                                                            │
                          ┌── локальный скилл? ──── да ─────┤  («включи музыку», «который час»)
                          │                                 │
                          └── нет ──▶ LLM (Claude / GPT) ────┘
                                                            │
                                            ответ ──▶ TTS ──▶ динамик
```

Двухуровневая обработка как в Home Assistant: простые команды отрабатывают скиллы мгновенно, остальное уходит в LLM.

## Быстрый старт (Windows / PowerShell)

```powershell
# 1. Установка (создаст .venv, поставит зависимости, создаст .env)
.\setup.ps1            # ядро + голосовой стек
# .\setup.ps1 -GPU       # + CUDA-ускорение распознавания (~1ГБ, нужна NVIDIA)
# .\setup.ps1 -CoreOnly  # только ядро (без голоса)

# 2. Скачай модели для голоса
.\.venv\Scripts\python.exe download_model.py        # распознавание команд (faster-whisper, ~484МБ)
.\.venv\Scripts\python.exe download_wake_model.py   # фраза активации (Vosk, ~45МБ)

# 3. Впиши ключи в .env
#    ANTHROPIC_API_KEY=...   (https://console.anthropic.com/)
#    OPENAI_API_KEY=...      (https://platform.openai.com/api-keys)

# 4. Запуск
.\run.ps1              # текстовый режим (чат в консоли)
.\run.ps1 -voice       # голосовой режим (микрофон + динамик)
.\run.ps1 -ui          # веб-панель управления (http://127.0.0.1:8000)
```

## Веб-панель управления (UI)

Локальная панель в браузере: выбор устройств ввода/вывода, громкость и живые
VU-метры, старт/стоп/пауза, статус (слушаю/думаю/говорю), живой лог диалога,
push-to-talk, вкладки настроек (нейросеть, голос+тест, wake-word, скиллы) и ввод
API-ключей. Аудио остаётся в Python-процессе — браузер лишь панель управления.

```powershell
# Зависимости панели (поверх ядра/голоса)
.\.venv\Scripts\python.exe -m pip install -r requirements-ui.txt

# Прод: собрать фронт и запустить один процесс на :8000
cd apps/web; npm install; npm run build; cd ../..
.\run.ps1 -ui                      # открой http://127.0.0.1:8000

# Дев: backend + Vite-дев с HMR (два терминала)
.\run.ps1 -ui                      # backend на :8000
cd apps/web; npm run dev           # фронт на :5173 (проксирует /api и /ws на :8000)
```

Стек: **FastAPI** (REST + WebSocket) + **Vite/React/TS/Tailwind/Zod** (Feature-Sliced
Design). Настройки сохраняются в [`config.yaml`](config.yaml) (комментарии не теряются),
ключи — в `.env` (в браузер отдаются только маской). Слушает `127.0.0.1` — только локально.

> Для голосового режима нужны микрофон и колонка/динамик. По умолчанию — **wake word**:
> ассистент постоянно слушает фразу активации («арс меджика»), затем пишет команду и сам
> определяет конец по паузе (~1.2 сек). Фраза/варианты — в `config.yaml` → `trigger.wakeword`.
> Откалибруй под свой голос:  `python -m tests.wake_calibrate live`.
> Альтернатива — `trigger.mode: push_to_talk` (активация по Enter).
>
> **GPU vs CPU.** По умолчанию `config.yaml` → `stt.device: cuda`. Если не ставил `-GPU`,
> переключи на `stt.device: cpu` и `compute_type: int8` — распознавание пойдёт на процессоре
> (для модели `small` это пара секунд на фразу).

## Переключение моделей

- Напиши/скажи **«Клод, ...»** — запрос уйдёт в Claude.
- **«ГПТ, ...»** — в GPT.
- Просто **«клод»** / **«гпт»** — переключает модель по умолчанию до следующей смены.

Модели и их триггеры настраиваются в [`config.yaml`](config.yaml).

## Скиллы

Локальные команды живут в [`src/skills.py`](src/skills.py). Сейчас есть:
- **музыка** — «включи музыку» (Spotify / YouTube Music)
- **время/дата** — «который час», «какое сегодня число»

Добавить свой: наследуйся от `Skill`, реализуй `match()` и `run()`, добавь в `Skills.__init__`.

## Конфигурация

Всё в [`config.yaml`](config.yaml): имя ассистента, модель по умолчанию, модели Claude/GPT,
параметры STT (модель Whisper, `cuda`/`cpu`), TTS, длительность записи.

## Статус и план

- [x] Текстовый режим: роутер, скиллы, Claude + GPT, переключение
- [x] Голосовой режим: запись с VAD, faster-whisper (STT), edge-TTS (рус. голос)
- [x] GPU-ускорение распознавания (CUDA 12 + cuDNN через pip, без системного CUDA)
- [x] Wake word: «дежурное» прослушивание фразы (Vosk-споттер) + калибровка по голосу
- [x] Веб-панель управления (FastAPI + React): устройства, громкость, VU-метры, лог, настройки, ключи
- [ ] Качественный локальный TTS (Piper / Silero)
- [ ] Function calling: чтобы LLM сама вызывала скиллы
- [ ] Вынос микрофона/динамика на 2-й телефон (спутник)

## Структура

```
config.yaml            конфиг
.env                   ключи API (не в git)
setup.ps1 / run.ps1    установка и запуск
src/
  main.py              точка входа, текстовый/голосовой циклы (поверх engine)
  config.py            загрузка/сохранение конфига и .env
  llm.py               агенты Claude/GPT + Router
  skills.py            локальные скиллы
  voice.py             запись, STT, TTS, триггер
  audio.py             устройства, громкость, уровни (VU)
  engine.py            управляемый движок (поток + события) для UI и CLI
  server/              FastAPI: REST + WebSocket (app, api, events, schemas)
apps/web/              веб-панель (Vite/React/TS/Tailwind, Feature-Sliced Design)
```
